# IBM Plex Sans

The typeface the visitor's slip is set in, shipped with the backend so that the receipt renders the
same here as it does on the machine driving the thermal printer in the entrance hall. Without it,
resvg falls back to whatever the host happens to have installed and the two slips stop matching.

Only the two weights the slip uses are here.
